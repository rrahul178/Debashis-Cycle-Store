# দোকান ম্যানেজার (Debashis Cycle Store)

ব্যাটারি, রিকশার পার্টস ও রিকশা বিক্রির দোকানের জন্য বাংলা হিসাব-নিকাশ সফটওয়্যার।
ডাটা ক্লাউডে (Supabase) থাকে, লগইন লাগে, একাধিক ডিভাইস/কর্মচারী একই হিসাব দেখতে পারে।

## ফিচার
- লগইন (ইমেইল + পাসওয়ার্ড)
- পণ্য ও স্টক (কম স্টকের সতর্কতা)
- বিক্রি → ইনভয়েস (প্রিন্টযোগ্য), বাকি/পরিশোধ, ছাড়
- ক্রয় (স্টক বাড়ে), সাপ্লায়ারের দেনা
- কাস্টমার/সাপ্লায়ার হিসাব খাতা, বাকি আদায়
- খরচের হিসাব
- দৈনিক / মাসিক / বার্ষিক রিপোর্ট
- ব্যাকআপ ডাউনলোড

## সেটআপ (একবারই করতে হবে)

### ১. Supabase প্রজেক্ট
1. supabase.com → GitHub দিয়ে সাইন আপ → **New project**
2. নাম: `dokan`, একটা Database Password দিন (লিখে রাখুন), Region: **Singapore** (বা Mumbai) → Create

### ২. ডাটাবেস টেবিল বানানো
1. বাঁদিকে **SQL Editor → New query**
2. `supabase/schema.sql` ফাইলের সবকিছু কপি করে paste করুন → **Run**
3. "Success" দেখালে হয়ে গেছে।

### ৩. ইউজার বানানো ও সাইন-আপ বন্ধ করা
1. **Authentication → Users → Add user → Create new user**
   ইমেইল + পাসওয়ার্ড দিন, **Auto Confirm User** টিক দিন। (মালিক ও প্রতিটি কর্মচারীর জন্য আলাদা ইউজার।)
2. **Authentication → Sign In / Providers** (বা Settings) এ গিয়ে **Allow new users to sign up** বন্ধ করুন, যাতে বাইরের কেউ অ্যাকাউন্ট বানাতে না পারে।

### ৪. কী বসানো
1. **Project Settings → API** থেকে **Project URL** ও **anon public** key কপি করুন।
2. GitHub-এ `config.js` খুলে (পেন্সিল আইকন) `YOUR_SUPABASE_URL` ও `YOUR_SUPABASE_ANON_KEY` এর জায়গায় বসান → Commit।
   (শুধু anon key বসাবেন, **service_role** key কখনো নয়।)

### ৫. Vercel
Vercel-এ repo ইম্পোর্ট করা থাকলে commit করলেই নিজে থেকে আবার deploy হবে। না থাকলে: **Add New → Project → repo সিলেক্ট → Deploy** (Framework: Other)।

## গুরুত্বপূর্ণ
- Supabase ফ্রি প্ল্যানে ৭ দিন একেবারে ব্যবহার না হলে প্রজেক্ট **pause** হয়ে যায়। নিয়মিত ব্যবহার করলে সমস্যা নেই; pause হলে Supabase ড্যাশবোর্ড থেকে **Restore** করুন।
- ফ্রি প্ল্যানে অটো ব্যাকআপ নেই, তাই সেটিংস থেকে মাঝে মাঝে **ব্যাকআপ ডাউনলোড** করে রাখুন।
- সব লগইন-করা ইউজার একই ডাটা দেখতে ও বদলাতে পারে (আলাদা মালিক/কর্মচারী পারমিশন এখনো নেই)।
