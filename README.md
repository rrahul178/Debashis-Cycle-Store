# দোকান ম্যানেজার (Debashis Cycle Store)

ব্যাটারি, রিকশার পার্টস ও রিকশা বিক্রির দোকানের জন্য বাংলা হিসাব-নিকাশ সফটওয়্যার।

## ফিচার
- পণ্য ও স্টক (কম স্টকের সতর্কতা)
- বিক্রি → ইনভয়েস (প্রিন্টযোগ্য), বাকি/পরিশোধ, ছাড়
- ক্রয় (স্টক বাড়ে), সাপ্লায়ারের দেনা
- কাস্টমার/সাপ্লায়ার হিসাব খাতা, বাকি আদায়
- খরচের হিসাব
- দৈনিক / মাসিক / বার্ষিক রিপোর্ট (বিক্রি, লাভ, খরচ, নিট লাভ, ক্যাশ)
- ব্যাকআপ ডাউনলোড ও রিস্টোর

## GitHub + Vercel-এ লাইভ করা
1. GitHub-এ নতুন repository খুলুন (যেমন `dokan-manager`), `index.html` ও `README.md` আপলোড করুন।
2. vercel.com এ GitHub দিয়ে লগইন → **Add New → Project** → repository সিলেক্ট → **Deploy**
   (Framework: Other, কোনো build command লাগবে না।)
3. কিছুক্ষণ পর লাইভ লিংক পাবেন।

## গুরুত্বপূর্ণ
তথ্য ব্যবহারকারীর ব্রাউজারে (localStorage) সেভ হয়। তাই একই ফোন/কম্পিউটার ও একই ব্রাউজার ব্যবহার করুন এবং নিয়মিত **সেটিংস → ব্যাকআপ** নিন।
